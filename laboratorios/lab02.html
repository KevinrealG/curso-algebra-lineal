Desarrollo del Laboratorio

EJEMPLO PROBLEMA: Programación de un robot móvil en la UTB

En el laboratorio de robótica de la UTB, un grupo de estudiantes programa un robot para desplazarse en línea recta por uno de los pasillos. El robot tiene tres movimientos básicos, llamados X, Y y Z, pero se desconoce la distancia y la dirección asociada con cada uno. Se establece la siguiente convención:

  • Los desplazamientos hacia el este son positivos.
  • Los desplazamientos hacia el oeste son negativos.

Para identificar los tres movimientos, los estudiantes realizan estas pruebas:

  • En la primera prueba, el robot ejecuta tres veces el movimiento X, seis veces el movimiento Y y tres veces el movimiento Z en sentido contrario. Al finalizar, queda 12 metros al este del punto de partida.
  • En la segunda prueba, ejecuta una vez X, dos veces Y y una vez Z. Termina 8 metros al este.
  • En la tercera prueba, ejecuta una vez cada movimiento. Termina 3 metros al este del punto de partida.

¿Cuál es la distancia y la dirección de cada movimiento?

  • X: desplazamiento producido por el movimiento X
  • Y: desplazamiento producido por el movimiento Y
  • Z: desplazamiento producido por el movimiento Z

Sistema de ecuaciones:

\( 3X + 6Y - 3Z = 12 \)

\( X + 2Y + Z = 8 \)

\( X + Y + Z = 3 \)

Eliminación gaussiana y Gauss-Jordan

Actividad 1: Creación de la matriz aumentada

  1. Defina la matriz de coeficientes A y el vector de constantes b para el sistema de ecuaciones de su problema asignado.
  2. Construya la matriz aumentada [A b].
  3. Imprima la matriz.

Código de ejemplo (para problema 1):

# Ejemplo Lab2
A = sp.Matrix([[3, 6, -3], [1, 2, 1], [1, 1, 1]])
b = sp.Matrix([12, 8, 3])

# Matriz aumentada
Aug = A.row_join(b)
print("Matriz aumentada:\n")
sp.pprint(Aug)

Actividad 2: Eliminación gaussiana usando el comando echelon_form

import sympy as sp
# Eliminación gaussiana (forma escalonada)
Aug_esc = Aug.echelon_form()
print("\nForma escalonada (Eliminacion gaussiana):\n")
sp.pprint(Aug_esc)

Actividad 3: Eliminación de Gauss-Jordan con el comando rref

import sympy as sp
A = sp.Matrix([[3, 6, -3], [1, 2, 1], [1, 1, 1]])
b = sp.Matrix([12, 8, 3])

# Gauss-Jordan:
Aug_red, pivotes = Aug.rref()
