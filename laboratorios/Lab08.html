Conceptos Matemáticos Involucrados

  • Combinación lineal: un vector P de $R^{3}$ es combinación lineal de $v_1, v_2$ y $v_3$ si existen escalares $a, b$ y $c$ tales que $P = a \cdot v_1 + b \cdot v_2 + c \cdot v_3$[cite: 92].
  • Conjunto generador: $\{v_1, v_2, v_3\}$ genera $R^{3}$ si todo vector de $R^{3}$ puede escribirse como combinación lineal de ellos con escalares reales[cite: 92].
  • Independencia lineal: $v_1, v_2$ y $v_3$ son linealmente independientes si la única solución de $a \cdot v_1 + b \cdot v_2 + c \cdot v_3 = 0$ es $a = b = c = 0$[cite: 92].
  • Base de $R^{3}$: conjunto de tres vectores linealmente independientes que genera $R^{3}$. Respecto a una base, los coeficientes de cada vector existen y son únicos[cite: 92].
  • Criterio del determinante: si $A = [v_1 \ v_2 \ v_3]$ es la matriz cuyas columnas son los tres vectores, estos son linealmente independientes si y solo si $\det(A) \neq 0$[cite: 92].
  • Coeficientes restringidos: en el videojuego cada pulsación suma un vector completo; por eso solo se admiten coeficientes enteros no negativos ($0, 1, 2, \dots$)[cite: 92].

# Verificacion de la Etapa 1 (ejecutar solo despues del trabajo manual)
vec1 = sp.Matrix([1, 1, 0])
vec2 = sp.Matrix([1, 0, 1])
vec3 = sp.Matrix([0, 1, 1])

# Matriz cuyas columnas son los vectores de movimiento
A = vec1.row_join(vec2).row_join(vec3)
print("Matriz A = [v1 v2 v3]:\n")
sp.pprint(A)
print("\ndet(A) =", A.det())

# Solucion de a*v1 + b*v2 + c*v3 = P para cada moneda
a, b, c = sp.symbols('a b c')
monedas = {
    "Moneda 1": sp.Matrix([3, 3, 2]),
    "Moneda 2": sp.Matrix([3, 2, 3]),
    "Moneda 3": sp.Matrix([1, 1, 1])
}
for nombre, P in monedas.items():
    solucion = sp.linsolve((A, P), a, b, c)
    print(f"\n{nombre} {tuple(P)}: (a, b, c) =", solucion)
