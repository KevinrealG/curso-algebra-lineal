Conceptos Matemáticos Involucrados

  • Combinación lineal: un vector P de $R^{3}$ es combinación lineal de $v_1, v_2$ y $v_3$ si existen escalares $a, b$ y $c$ tales que $P = a \cdot v_1 + b \cdot v_2 + c \cdot v_3$.
  • Conjunto generador: $\{v_1, v_2, v_3\}$ genera $R^{3}$ si todo vector de $R^{3}$ puede escribirse como combinación lineal de ellos con escalares reales.
  • Independencia lineal: $v_1, v_2$ y $v_3$ son linealmente independientes si la única solución de $a \cdot v_1 + b \cdot v_2 + c \cdot v_3 = 0$ es $a = b = c = 0$.
  • Base de $R^{3}$: conjunto de tres vectores linealmente independientes que genera $R^{3}$. Respecto a una base, los coeficientes de cada vector existen y son únicos.
  • Criterio del determinante: si $A = [v_1 \ v_2 \ v_3]$ es la matriz cuyas columnas son los tres vectores, estos son linealmente independientes si y solo si $\det(A) \neq 0$.
  • Coeficientes restringidos: cada movimiento suma un vector completo; por eso solo se admiten coeficientes enteros no negativos ($0, 1, 2, \dots$).

Importante: La matriz, el determinante, los sistemas y las clasificaciones deben aparecer como salida del programa Python.

from fractions import Fraction
from typing import Iterable


Vector = tuple[Fraction, ...]


def vector(*components: int) -> Vector:
    return tuple(Fraction(component) for component in components)


def linear_combination(vectors, coefficients):
    """Calcula a*v1 + b*v2 + c*v3."""
    return tuple(
        coefficients[0] * vectors[0][row]
        + coefficients[1] * vectors[1][row]
        + coefficients[2] * vectors[2][row]
        for row in range(3)
    )


def matrix(vectors):
    """Construye la matriz A = [v1 v2 v3]."""
    return [[vectors[column][row] for column in range(3)] for row in range(3)]


def gauss_jordan(matrix_a, P):
    """Resuelve Ax = P por eliminación de Gauss-Jordan."""
    augmented = [
        row[:] + [P[row_index]]
        for row_index, row in enumerate(matrix_a)
    ]

    pivot_row = 0
    for column in range(3):
        pivot = next(
            (row for row in range(pivot_row, 3)
             if augmented[row][column] != 0),
            None,
        )
        if pivot is None:
            continue

        augmented[pivot_row], augmented[pivot] = (
            augmented[pivot],
            augmented[pivot_row],
        )
        pivot_value = augmented[pivot_row][column]
        augmented[pivot_row] = [
            value / pivot_value for value in augmented[pivot_row]
        ]

        for row in range(3):
            if row == pivot_row:
                continue
            factor = augmented[row][column]
            augmented[row] = [
                augmented[row][index]
                - factor * augmented[pivot_row][index]
                for index in range(4)
            ]
        pivot_row += 1

    for row in augmented:
        if all(value == 0 for value in row[:3]) and row[3] != 0:
            return augmented, None

    if pivot_row < 3:
        return augmented, None

    return augmented, [augmented[row][3] for row in range(3)]


def determinant3(matrix_a):
    a, b, c = matrix_a[0]
    d, e, f = matrix_a[1]
    g, h, i = matrix_a[2]
    return (
        a * (e * i - f * h)
        - b * (d * i - f * g)
        + c * (d * h - e * g)
    )


def integer_nonnegative(solution):
    return solution is not None and all(
        value.denominator == 1 and value >= 0
        for value in solution
    )


def format_vector(value: Iterable[Fraction]) -> str:
    return "(" + ", ".join(str(component) for component in value) + ")"


def analyze_base(vectors, objectives):
    matrix_a = matrix(vectors)
    det = determinant3(matrix_a)

    print("\nMatriz A:")
    for row in matrix_a:
        print(format_vector(row))
    print("det(A) =", det)
    print("¿Es una base?", "Sí" if det != 0 else "No")

    for name, position in objectives.items():
        augmented, solution = gauss_jordan(matrix_a, position)
        reachable = integer_nonnegative(solution)

        coefficients = (
            tuple(int(value) for value in solution)
            if reachable
            else solution
        )

        print(f"\n{name}: P = {format_vector(position)}")
        print("Matriz aumentada:")
        for row in augmented:
            print(format_vector(row[:3]) + " | " + str(row[3]))
        print("Solución (a, b, c):", coefficients)
        print("Clasificación:",
              "ALCANZABLE" if reachable else "NO ALCANZABLE")

        if reachable:
            print("Pulsaciones:", coefficients)

Funciones disponibles

  • matrix(vectors): construye la matriz cuyas columnas son los vectores.
  • determinant3(matrix_a): calcula el determinante con Python.
  • gauss_jordan(matrix_a, P): obtiene la matriz aumentada y resuelve el sistema.
  • integer_nonnegative(solution): clasifica si los coeficientes son enteros no negativos.
  • linear_combination(vectors, coefficients): genera una posición a partir de una terna.
  • analyze_base(vectors, objectives): verifica la base y clasifica todos los objetivos.
