5. Problema de Aplicación[cite: 6]

Se requiere encontrar el polinomio cúbico de la forma $y=a\cdot x^{3}+b\cdot x^{2}+c\cdot x+d$ que pase exactamente por los siguientes cuatro puntos dados en el plano cartesiano[cite: 6]:

  • Puntos dados: (0, 2), (1, 1), (2, 4) у (3, 11)[cite: 6].
  • Variables a determinar: a, b, c, d[cite: 6].

Planteamiento del sistema sustituyendo cada punto en la ecuación cúbica[cite: 6]:

  1. Para (0, 2): $a(0)^{3}+b(0)^{2}+c(0)+d=2==>d=2$[cite: 6]
  2. Para (1, 1): $a(1)^{3}+b(1)^{2}+c(1)+d=1==>a+b+c+d=1$[cite: 6]
  3. Para (2, 4): $a(2)^{3}+b(2)^{2}+c(2)+d=4==>8a+4b+2c+d=4$[cite: 6]
  4. Para (3, 11): $a(3)^{3}+b(3)^{2}+c(3)+d=11==>27a+9b+3c+d=11$[cite: 6]

6. Procedimiento[cite: 6]

Para resolver el problema planteado, realizamos los siguientes pasos[cite: 6]:

  • Paso 1: Armamos la matriz de coeficientes A, el vector b y la matriz aumentada [Alb] con las ecuaciones obtenidas de sustituir los puntos[cite: 6].
  • Paso 2: Aplicamos el método de eliminación gaussiana mediante operaciones elementales de fila para simplificar la matriz aumentada y encontrar las respuestas[cite: 6].
  • Paso 3: Verificamos los resultados utilizando Python con la libreria SymPy, usando funciones de cálculo simbólico como rref() y linsolve()[cite: 6].

Ecuación del Polinomio Cúbico Obtenido[cite: 6]:

Sustituyendo los valores $a=0$ $b=2$ $c=-3$ y $d=2$ en la ecuación $y=a\cdot x^{3}+b\cdot x^{2}+c\cdot x+d$ obtenemos[cite: 6]:

$y=2x^{2}-3x+2$[cite: 6]

(Nota: Como el coeficiente a dio 0, la función resultante se reduce a una parábola de segundo grado)[cite: 6].

Preguntas de Interpretación[cite: 6]

  1. Significado de la solución obtenida: Cada variable (a, b, c, d) representa los coeficientes del polinomio que define la curva[cite: 6]. En un contexto práctico o físico, d es el valor inicial cuando $x=0,$ c representa la inclinación o cambio inicial, y by a controlan la curvatura del modelo[cite: 6]. El valor numerical hallado nos da la fórmula exacta con la que podemos predecir valores intermedios o futuros de los datos[cite: 6].
  2. Caso de infinitas soluciones: Si el sistema tuviera infinitas soluciones, significaría que los puntos dados no son suficientes para fijar una sola curva (por ejemplo, tener solo 2 o 3 puntos para una cúbica)[cite: 6]. Para obtener una solución única, se tendría que agregar una condición o punto experimental extra que restrinja las opciones a una sola curva[cite: 6].
  3. Caso de sistema sin solución: Si el sistema no tuviera solución, indicaría que los puntos no pueden ser conectados exactamente por una sola curva polinómica (tal vez por errores de medición)[cite: 6]. La solución sería usar un método de aproximación como mínimos cuadrados, o ajustar un modelo de mayor grado[cite: 6].
  4. Comparación de eliminación gaussiana y rref(): Ambos métodos llegan exactamante a la misma solución final[cite: 6]. La ventaja de rref() es que es mucho más rápido y evita errores humanos al hacer operaciones algebraicas a mano, mientras que el paso a paso sirve para entender cómo funciona el procedimiento por dentro[cite: 6].
  5. Ventajas y desventajas de SymPy vs. NumPy: SymPy trabaja de forma simbólica (con fracciones exactas y sin perder precisión), lo cual es ideal para este tipo de ejercicios académicos[cite: 6]. NumPy hace cálculos numéricos muy rápidos con decimales, pero en ocasiones puede tener ligeros redondeos[cite: 6].
  6. Efecto de cambiar coeficientes: Si se cambia un coeficiente o un valor constante del sistema (como los valores y de los puntos), la curva resultante cambiará de forma, posición o inclinación, ajustándose a los nuevos datos ingresados[cite: 6].
