CONTENIDOS TEÓRICOS

  1. Determinante de una matriz: El determinante es una función que asigna a cada matriz cuadrada A un número real denotado por $det(A)$ o $|A|$. Para una matriz $2 imes2$: $det([[a,b],[c,d]])=a\cdot d-b\cdot c$
    Para matrices de orden superior, el determinante se calcula mediante expansión por cofactores o por reducción por filas (eliminación gaussiana).
  2. Propiedades fundamentales:
    • $det(A\cdot B)=det(A)\cdot det(B)$
    • $det(A^{T})=det(A)$
    • $det(A^{-1})=1/det(A)$ si A es invertible
    • Si una fila o columna es múltiplo de otra, $det(A)=0$
    • Si se intercambian dos filas, el determinante cambia de signo
    • Si se multiplica una fila por k, el determinante se multiplica por k
  3. Relación con la invertibilidad: Una matriz cuadrada A es invertible si y solo si $det(A) e0$. Además, el sistema $Ax=b$ tiene solución única si y solo si $det(A) e0$.
  4. Regla de Cramer: Para un sistema $Ax=b$ con $det(A) e0$, la solución está dada por: $x_i=det(A_i)/det(A)$, donde $A_i$ es la matriz A con la columna i reemplazada por b.
  5. Interpretación geométrica: El valor absoluto del determinante de una matriz $2 imes2$ representa el área del paralelogramo formado por sus columnas. Para una matriz $3 imes3$, representa el volumen del paralelepípedo.

PROBLEMA 0 (EJEMPLO RESUELTO): Ajuste de una órbita elíptica

Disciplina: Astronomía/Física

Contexto: Un astrónomo quiere determinar la órbita de un asteroide alrededor del Sol. La ecuación general de una cónica es: $Ax^{2}+Bxy+Cy^{2}+Dx+Ey+F=0$. Se tienen cinco observaciones de la órbita.

Datos observados (x, y): (5.764, 0.648), (6.286, 1.202), (6.759, 1.823), (7.168, 2.526), (7.480, 3.360)

Solución paso a paso:

Paso 1: Plantear el sistema de ecuaciones
Sustituyendo cada punto en $Ax^{2}+Bxy+Cy^{2}+Dx+Ey+F=0$ y fijando $F=1$, se obtiene un sistema de 5 ecuaciones con 5 incógnitas (A, B, C, D, E).

Paso 2: Código en Python

import numpy as np
import sympy as sp
import matplotlib.pyplot as plt

# Datos observados
puntos = np.array([
    [5.764, 0.648],
    [6.286, 1.202],
    [6.759, 1.823],
    [7.168, 2.526],
    [7.480, 3.360]
])
x, y = puntos[:, 0], puntos[:, 1]

# Construir matriz A (5x5) y vector b (5x1) con F=1
A = np.column_stack([x**2, x*y, y**2, x, y])
b = -np.ones(5)
print("
Matriz A:
")
sp.pprint(sp.Matrix(A))
print("
Vector b:
")
sp.pprint(sp.Matrix(b))

# Calcular determinante
det_A = np.linalg.det(A)
print("
Determinante de A:", det_A)

# Resolver el sistema
if abs(det_A) > 1e-10:
    coef = np.linalg.solve(A, b)
    A_, B_, C_, D_, E_ = coef
    F_ = 1.0
    print("
Coeficientes (A,B,C,D,E,F):")
    print(f"A={A_:.6f}, B={B_:.6f}, C={C_:.6f}")
    print(f"D={D_:.6f}, E={E_:.6f}, F={F_:.6f}")
    
    # Verificacion
    Ax = A @ coef
    error = np.max(np.abs(Ax - b))
    print("
Error maximo:", error)
    
    # Grafica
    fig, ax = plt.subplots(figsize=(8, 6))
    ax.plot(x, y, 'ro', label='Observaciones', markersize=8)
    theta = np.linspace(0, 2*np.pi, 400)
    xv = np.linspace(5.5, 7.8, 200)
    yv = np.linspace(0.3, 3.7, 200)
    X, Y = np.meshgrid(xv, yv)
    Z = A_*X**2 + B_*X*Y + C_*Y**2 + D_*X + E_*Y + F_
    ax.contour(X, Y, Z, levels=[0], colors='b')
    ax.set_xlabel('x (UA)')
    ax.set_ylabel('y (UA)')
    ax.set_title('Orbita del asteroide')
    ax.legend()
    ax.grid(True)
    plt.show()
else:
    print("
La matriz no es invertible.")
