Semana 15 - Valores y vectores propios

Objetivo: entender la estructura interna de una transformación lineal.

Se introduce el concepto de autovalor, autovector y diagonalización.

Autovalores y autovectores

Un vector no nulo \(v\) es autovector si existe un escalar \(\lambda\) tal que:

\[ Av = \lambda v \]

El número \(\lambda\) se llama autovalor.

Cálculo de autovalores

Para encontrar autovalores se resuelve:

\[ \det(A - \lambda I) = 0 \]

Esta ecuación define el polinomio característico de la matriz.

Autovectores asociados

Una vez se conoce \(\lambda\), se resuelve el sistema:

\[ (A - \lambda I)v = 0 \]

Las soluciones no triviales forman el espacio propio asociado.

Diagonalización

Una matriz es diagonalizable si puede escribirse como:

\[ A = PDP^{-1} \]

Esto facilita el cálculo de potencias y otros procesos algebraicos.

Aplicaciones

Los autovalores y autovectores se usan en sistemas dinámicos, estabilidad y análisis espectral.

  • Modelos de crecimiento
  • Dinámica de sistemas
  • Procesamiento de datos
