Vectores en el Plano (\(\mathbb{R}^2\))

Definición Geométrica de un Vector

El conjunto de todos los segmentos de recta dirigidos equivalentes a un segmento de recta dirigido dado se llama vector.

Cualquier segmento de recta en ese conjunto se denomina representación del vector. Esto significa que, en el plano, podemos trasladar el segmento manteniendo su longitud y dirección, y seguirá representando el mismo vector físico.

Definición Algebraica

Definición Algebraica de un Vector

Un vector \( \mathbf{v} \) en el plano \( xy \) es un par ordenado de números reales \( (a, b) \).

\[ \mathbf{v} = (a, b) \]

Los números \( a \) y \( b \) se denominan elementos o componentes del vector \( \mathbf{v} \). El vector cero es el par ordenado \( (0, 0) \).

Magnitud de un Vector

La magnitud o longitud de un vector se define utilizando el teorema de Pitágoras.

Para un vector \( \mathbf{v} = (a, b) \), su magnitud, denotada como \( |\mathbf{v}| \), se calcula con la siguiente fórmula:

\[ |\mathbf{v}| = \sqrt{a^2 + b^2} \]
Ejemplo: Para el vector \( (3, 4) \), la magnitud es \( \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = 5 \).

Dirección de un Vector

Se define la dirección de un vector \( \mathbf{v} = (a, b) \) como el ángulo \( \theta \), medido en radianes, que forma el vector con el lado positivo del eje \( x \).

Por convención, se escoge \( \theta \) tal que \( 0 \le \theta < 2\pi \). La dirección se puede deducir usando trigonometría básica:

\[ \tan \theta = \frac{b}{a} \quad (\text{si } a \neq 0) \]

Nota: Es necesario determinar en qué cuadrante se encuentra el vector para calcular el ángulo correcto mediante \( \arctan \).

Producto por un Escalar

Al multiplicar un vector \( \mathbf{v} \) por un escalar \( \alpha \), su magnitud se escala:

\[ |\alpha \mathbf{v}| = |\alpha| \sqrt{a^2 + b^2} = |\alpha| |\mathbf{v}| \]

Efecto en la Dirección:

  • Si \( \alpha > 0 \), entonces \( \alpha \mathbf{v} \) está en el mismo cuadrante que \( \mathbf{v} \) y tiene la misma dirección.
  • Si \( \alpha < 0 \), entonces \( \alpha \mathbf{v} \) tiene la dirección opuesta a la de \( \mathbf{v} \).

La Desigualdad del Triángulo

Una de las propiedades geométricas más importantes al sumar vectores es la desigualdad del triángulo.

Para cualesquiera dos vectores \( \mathbf{u} \) y \( \mathbf{v} \), se cumple que:

\[ |\mathbf{u} + \mathbf{v}| \le |\mathbf{u}| + |\mathbf{v}| \]
Interpretación: Esta desigualdad formaliza el hecho geométrico de que un segmento de recta es la distancia más corta entre dos puntos.

Vectores Base en \(\mathbb{R}^2\)

Existen dos vectores especiales en \(\mathbb{R}^2\) que nos permiten representar a cualquier otro vector en el plano de una forma conveniente[cite: 40].

Se denota el vector \((1, 0)\) por el símbolo \(\mathbf{i}\) y el vector \((0, 1)\) por el símbolo \(\mathbf{j}\)[cite: 40].

Si \(\mathbf{v} = (a, b)\) es cualquier vector en el plano, entonces como \((a, b) = a(1, 0) + b(0, 1)\), se puede escribir[cite: 40]:

\[ \mathbf{v} = (a, b) = a\mathbf{i} + b\mathbf{j} \]
(4.1.6)

Con esta representación se dice que \(\mathbf{v}\) está expresado en sus componentes horizontal y vertical[cite: 40].

Representación Algebraica de un Vector Unitario

Sea \(\mathbf{u} = a\mathbf{i} + b\mathbf{j}\) un vector unitario. Entonces:

\[ |\mathbf{u}| = \sqrt{a^2 + b^2} = 1 \]

De manera que \(a^2 + b^2 = 1\) y se hace claro (por trigonometría en la figura 4.10) que[cite: 41]:

  • \( a = \cos \theta \)
  • \( b = \operatorname{sen} \theta \)

De este modo, cualquier vector unitario \(\mathbf{u}\) se puede escribir en la forma[cite: 41]:

Representación de un vector unitario

\[ \mathbf{u} = (\cos \theta)\mathbf{i} + (\operatorname{sen} \theta)\mathbf{j} \]
(4.1.7)

donde \(\theta\) es la dirección de \(\mathbf{u}\)[cite: 41].
