Cuándo existe una solución única o infinitas.

Un sistema es homogéneo cuando todos los términos independientes son cero

a11x1 + a12x2 + ⋯ + a1nxn = 0
a21x1 + a22x2 + ⋯ + a2nxn = 0
⋮
am1x1 + am2x2 + ⋯ + amnxn = 0
Forma matricial
Ax = 0
La clave
b = 0

Los coeficientes pueden ser distintos de cero; lo que debe ser cero es el vector b.

La diferencia entre ambos sistemas está únicamente en el vector b

Homogéneo

Ax = 0

Todos los bi son cero

Siempre es consistente

No homogéneo

Ax = b

Algún bi es distinto de cero

Puede ser inconsistente

Todo sistema homogéneo tiene, al menos, la solución cero

Solución trivial

x1 = x2 = ⋯ = xn = 0

Al sustituir, cada ecuación queda 0 = 0.

A partir de aquí solo hay dos posibilidades

La solución trivial es única
o
Existen infinitas soluciones

1 · Intuición Geométrica

La idea de “lineal” comienza con la recta

y = mx + b
m = Δy / Δx
  • m pendiente
  • b intercepto con el eje y

Una ecuación lineal en dos variables representa una recta.
